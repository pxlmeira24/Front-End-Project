# 🖥️ Front-End Project

Projeto desenvolvido para prática e aplicação de conceitos de **desenvolvimento front-end**, utilizando tecnologias fundamentais da web como **HTML, CSS e JavaScript**.

O projeto conta com uma estrutura organizada em arquivos de estilo, scripts, imagens e diferentes telas da aplicação.

## 📌 Sobre o projeto

O **Front-End Project** foi desenvolvido com o objetivo de colocar em prática conhecimentos de desenvolvimento web, trabalhando principalmente com:

* Estruturação de páginas com HTML;
* Estilização e criação de layouts com CSS;
* Interatividade e comportamento da página com JavaScript;
* Organização de arquivos e recursos do projeto;
* Criação de diferentes telas para a aplicação;
* Utilização de imagens e outros recursos visuais.

## 🚀 Tecnologias utilizadas

| Tecnologia     | Utilização                               |
| -------------- | ---------------------------------------- |
| **HTML5**      | Estrutura das páginas                    |
| **CSS3**       | Estilização e layout                     |
| **JavaScript** | Interatividade e funcionalidades         |
| **Git/GitHub** | Versionamento e gerenciamento do projeto |

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/pxlmeira24/Front-End-Project.git
```

### 2. Entre na pasta

```bash
cd Front-End-Project
```

### 3. Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript, basta abrir o arquivo `index.html` no navegador.

Uma alternativa é utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto em um servidor local.
